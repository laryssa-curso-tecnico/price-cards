# Price Cards

Uma página de cartões de preços para apresentar diferentes planos e seus respectivos valores e benefícios de forma organizada.

## Funcionalidades

- Exibição de diferentes planos
- Apresentação de preços
- Exibição de benefícios de cada plano
- Destaque visual entre os planos
- Layout organizado e responsivo

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
